# Dimensionamento UPS anterior — substituído

A meta de13horas e a propostaLiFePO4 4S20Ah foram retiradas pelo usuário. Não usar estes números para BOM, compra, gabinete ou validação. O requisito atual é bateriaLiPo plana interna leve, com autonomia a definir. Ver [INTERNAL_BATTERY.md](INTERNAL_BATTERY.md) e REQ-011.
