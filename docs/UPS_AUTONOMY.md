# Dimensionamento UPS anterior — substituído

A meta de 13 horas e a proposta LiFePO4 4S 20 Ah foram retiradas pelo usuário. Não usar estes números para BOM, compra, gabinete ou validação. O requisito atual é bateria LiPo plana interna leve, com autonomia a definir. Ver [INTERNAL_BATTERY.md](INTERNAL_BATTERY.md) e REQ-011.
